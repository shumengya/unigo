>引言:书同文，车同轨。用强制统一的语法去规范各个奇技淫巧的写法,让语言更易读更易懂,减少程序写代码的心智成本,不像Python过于简约,也不像Java过于臃肿,
>不像Cpp过于华丽花哨,像json那样在人和机器之间建立一种平衡,这也是我在语言基座中选择Golang而不是Rust,TypeScript,Cpp的初衷,每种语言都有他匹配的场景和领域,也有他自己的优缺点,没有最完美的语言只有最适合特定场景的工具
- 类似 TypeScript 之于 JavaScript，Kotlin 之于 Java。Garnet 基于 Go 的生态，解决 Go 语法臃肿、容易混淆的问题。编译路径为 .gn 源代码 -> .go 源代码 -> 各平台二进制文件
- 语言暂定为 Garnet，文件后缀为 .gn
- 兼容的是 Go 的库、包和函数，可以导入后调用。不是兼容 Go 源码。Go 源码不能直接当 Garnet 源码编译
- 转译器名字叫 garnet，命令是 garnet build main.gn。Garnet 自己解析 .gn。生成 Go 时使用 Go 的语法树和打印器。不能用 go/parser 解析 .gn
- 语法必须简洁、易读。可以参考 Java、TypeScript、Python 的写法，但每种意思只保留一种写法
- 注释还是使用//，也有且仅有这一种注释形式
- 包还是 package main，结尾必须写分号：package main; 不写分号编译不通过
- 导入一行一条，必须写成 import 名字 from "路径"; 结尾必须写分号。例如 import fmt from "fmt"; import os from "os"; import json from "encoding/json"; import png from "image/png"; 不写分号编译不通过。禁止 import "路径"，禁止 import ()，禁止 import _
- 变量使用 var，类型后置，必须带类型。单个值写成 var str1 :string = "这是字串符"; 冒号后面不写类型会报错。多个值必须放进圆括号：var (data :byte[], err :error) = os.ReadFile(path); 禁止不写括号的 var data :byte[], err :error = os.ReadFile(path);
- 常量使用 const，类型后置，必须带类型和分号。写法为 const tStr :string = "hello"; 不写类型或不写分号编译不通过。一条 const 只能有一个类型
- 条件必须放在括号里，分支必须用花括号。写法为 if (条件) {}、if (条件) {} else {}、if (条件) {} elif (条件) {}、while (条件) {}、for (条件) {}。不写括号或花括号编译不通过。比较使用 ==、!=、>、>=、<、<=
- 已声明的变量可以重新赋值，写成 count = count - 1; 赋值不改类型，不能写成 count :int = 1。映射写入写成 scores["语文"] = 100;
- 取地址写成 &item。指针类型写成 *os.File，冒号紧贴星号。需要改结构体内容的 Go 函数必须传地址，如 json.Unmarshal(raw, &item)
- 枚举是独立类型，不能和 int、string 直接混算。写法为 enum Status { ready; failed; empty; } 使用时写成 Status.ready。禁止 iota。禁止把枚举当整数用
- switch 的条件放在括号里，每个 case 和 default 都用花括号，不写冒号，没有 fallthrough。枚举必须列全所有成员，漏一个就编译不通过，并且禁止 default。其他类型必须写 default。写法为 switch (state) { case Status.ready { } case Status.failed { } case Status.empty { } } 每个分支都 return 时，枚举 switch 视为已经返回，函数末尾不必再写 return
- 变量和函数命名有长度限制。纯英文或数字至少两个字符，禁止 a，允许 ab、a2、abc。中文或其他字符至少两个字符，禁止 阿，允许 世界。少于这个长度直接编译不通过
- 类型后置只能写成 名字 :类型。冒号前面有一个空格，冒号必须紧贴类型。禁止 名字: 类型、禁止 名字:类型。不这样写编译不通过
- 切片的 [] 后置在类型上。写成 var str1 :string[] = ["awd", "adwa", "awdawd"]; 右边只写方括号字面量，不重复元素类型。禁止 []string，禁止 string[]("awd", "adwa")，禁止 []("awd", "adwa")
- 映射关键字是 map。类型是 map[键, 值]，字面量用花括号和冒号：var scores :map[string, int] = {"语文": 90, "数学": 86}; 读取、写入用方括号：var score :int = scores["语文"]; var (score :int, found :bool) = scores["数学"]; scores["语文"] = 100; 删除写成 delete(scores, "语文"); 禁止 map[string]int，禁止 dict[string, int]，禁止 {"语文" = 90}
- 函数方法默认还是 func。可以有多个参数，返回值只能有一个。写法为 func printStudent(student :string) :string{} 没有返回值时不写冒号，如 func main(){} 禁止 Garnet 自己的函数写多个返回值，禁止 func readFile(path :string) :(data :byte[], err :error) {}
- 结构体只放字段，不放函数。大的数据用有名字的字段把小结构体组合进去，不靠继承。写法为 struct Student { name :string; age :int; } 字面量写成 Student{name = "树萌芽", age = 18} 没写的字段是零值。禁止在结构体里写 func。禁止 class、new、extends、implements
- 接口只放函数，不放字段。它是插件插口。写法为 interface StudentParser { func parse(raw :string) :Student; } 组装写成 return StudentParser{ func parse(raw :string) :Student { return parseStudent(raw); }; }; 不写 implements，也没有 extends。缺函数或类型对不上，编译不通过
- JSON 文本用 string 传入。写法为 var err :error = json.Unmarshal(raw, &item) else return Student{}; 转译时把 string 转成 []byte 再调用 Go 的 Unmarshal。字段名就是 JSON 的键，生成的 Go 字段会导出，并加上同名 json 标签。嵌套对象对应嵌套结构体，数组对应切片
- 新类型和别名用不同关键字，再用等号分开名字和类型。新类型写成 newtype Celsius = float64; 它和 float64 不能直接混算。别名写成 alias Kelvin = float64; 它和 float64 是同一个类型。禁止 newtype Celsius :float64; 禁止 newtype Celsius float64; 禁止 type Celsius float64; 禁止 type Kelvin = float64;
- 只有接收 Go 库的多个返回值、并且左边写出两个及以上的值时，才使用圆括号。写法为 var (written :int, printErr :error) = fmt.Println(data); error 可以省略。省略后如果只剩一个值，必须写成 var written :int = fmt.Println(data); 禁止 var (written :int) = fmt.Println(data); 省略后没有 else return 时，error 直接丢掉。花括号是代码块、结构体字面量、插件组装和映射，后置的 [] 是切片，都不能用来接收多个返回值。禁止 data, err := os.ReadFile(path); 禁止 return (data, err); 非 error 的返回值个数或类型对不上，编译不通过
- 失败就返回，写在调用同一行的末尾：var (data :byte[], err :error) = os.ReadFile(path) else return err; 函数返回的不是 error 时，必须写出返回值，如 else return Student{}; 省略了 error、函数返回类型又是 error 时，写成 else return; 表示返回那个被省略的 error。函数返回类型不是 error 时，禁止裸写 else return; 要按错误种类分支时，仍用 if (err != nil) {}
