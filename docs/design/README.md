# 设计决策记录

记录"为什么这样定"，避免以后重复讨论同一个问题。每条一个文件，文件名用 `NNNN-简短标题.md`，
内容写：背景、考虑过的方案、最终决定、代价。

## 白皮书中已定、待补记录的决定

- 类型后置，只能写成 `名字 :类型`
- 注释只有 `//`
- Garnet 自己的函数只能有一个返回值
- 枚举是独立类型，禁止当整数用，switch 必须列全成员
- 结构体只放字段、接口只放函数，不用继承
- `newtype` 与 `alias` 用两个关键字区分
