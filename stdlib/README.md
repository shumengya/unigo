# 标准库

**规划中，尚未开始。**

UniGo 可以导入并调用 Go 的包，所以短期不需要自己写标准库。
这个目录留给 UniGo 特有的能力：那些用 Go 表达不自然、需要在语言层提供的东西。

## 计划

- `errors.ug`：统一的错误传递与判断（等 `else return` 的语义定型后再写）
- `collections.ug`：切片的查找、去重、映射等常用操作
- `strings.ug`：常用字符串处理

## 约定

- 每个包一个目录，目录名即包名，入口文件与目录同名。
- 必须能用 `unigo build` 通过，并被 `tests/pass` 覆盖。
- 只用 Go 标准库，不引入第三方依赖。
